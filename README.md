# Lecture Drift Detector

**Cross-Lecture Concept Consistency Tracking using ASR & LLM-based Semantic Analysis**

This repository contains the code and documentation for the Lecture Drift Detector project. The system tracks how the explanation of each concept changes across an entire lecture series, classifies the nature of that change, and visualizes it as a per-concept timeline.

## Features
- **Speech-to-Text**: Automated transcription using Whisper.
- **Multimodal Alignment**: Synchronizes audio transcripts with visual scene changes (slides, diagrams).
- **Concept Tracking**: Groups topically coherent segments across different lectures.
- **Drift Classification**: Evaluates the evolution of concepts as Consistent, Refinement, Correction, or Contradiction.
- **Visual Timeline**: Presents an interactive timeline of how ideas evolved throughout the course.
